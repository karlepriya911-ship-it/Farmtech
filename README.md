# FarmTech Rental System

A simple PHP/MySQL agricultural equipment rental system for farmers, equipment owners, and administrators.

## Quick start

1. Copy the repository into XAMPP's `htdocs` directory.
2. Start Apache and MySQL in XAMPP.
3. Import `database/farmtech.sql` using phpMyAdmin.
4. Update credentials in `backend/config/db_config.php` if needed.
5. Open `http://localhost/Farmtech/frontend/index.html`.

## Stack

HTML, CSS, JavaScript, Bootstrap, PHP, and MySQL.

## Included starter features

- Responsive landing page and equipment catalog
- Farmer/owner registration and login API
- Equipment browsing API
- Booking creation API
- Database schema for users, equipment, bookings, payments, reviews, complaints, and admins

This project is intended for educational use.
